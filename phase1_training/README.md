# 🌱 Phase 1 — 語感リセット訓練（7月〜8月・8週間）

**目標**：中国語を経由せず「状況→日本語」が直結する語感を作る

## 📁 このフォルダの内容

| ファイル | 内容 |
|---------|------|
| `README.md` | このファイル。Phase 1 概要 |
| `phrases_100.js` | 暗唱100フレーズ（トレーナーへの組み込み用） |
| `daily_routine.md` | 毎日60分のルーティン詳細 |
| `week_checklist.md` | 週別チェックリスト（8週間分） |

## ⏱️ 毎日60分ルーティン

| 時間 | 内容 |
|------|------|
| 15分 | シャドーイング（NHK for School / アニメ） |
| 15分 | 暗唱100句の反復（声に出す＋録音） |
| 15分 | 実況独り言（目の前の状況を日本語で） |
| 15分 | 発音矯正（拗音・促音・アクセント） |

## 🗓️ 週別テーマ

| 週 | テーマ |
|----|--------|
| Week 1〜2 | 発音慣らし・相槌20句マスター |
| Week 3〜4 | シャドーイング85%速度・自己紹介20句 |
| Week 5〜6 | 理由・説明15句 / 実況独り言3分 |
| Week 7〜8 | 全100句反射出力・フリートーク5分 |

## ✅ Phase 1 修了基準
- [ ] 100フレーズが反射的に口から出る
- [ ] シャドーイングをネイティブ等速で追える
- [ ] 5分間の実況独り言ができる
