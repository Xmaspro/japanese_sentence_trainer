# ⏱️ 毎日60分ルーティン — Phase 1 詳細

## ルーティン概要

```
[15分] ① シャドーイング
[15分] ② 暗唱フレーズ反復
[15分] ③ 実況独り言練習
[15分] ④ 発音・アクセント矯正
```

---

## ① シャドーイング（15分）

### 速度スケジュール
| 週 | 速度 | Youtubeの設定 |
|----|------|--------------|
| Week 1〜2 | 70% | 再生速度 0.75 |
| Week 3〜4 | 85% | 再生速度 0.85 |
| Week 5〜6 | 95% | 再生速度 0.95 |
| Week 7〜8 | 100% | 再生速度 1.0（等速） |

### やり方（ステップ）
1. **音だけ聞く**（1回）— 意味は気にしない、音とリズムを感じる
2. **止めながら復唱**（1文ずつ）— 完全に真似する
3. **追いかけながら**（止めずに）— 本当のシャドーイング
4. **録音して聞く**— 1週間後に聞き直す

### 推薦素材

| 素材名 | URL / 検索 | 特徴 | Week |
|--------|-----------|------|------|
| NHK for School「ひょっこりはんてん」| nhk.or.jp/school | ゆっくり・自然な会話 | 1〜4 |
| NHK for School「Why!?大百科」| nhk.or.jp/school | 日常場面 | 3〜6 |
| ちびまる子ちゃん（アニメ）| YouTube | 口語・日常 | 3〜8 |
| NHK Web Easy 音声 | nhk.or.jp/news/easy | 標準語・やや速い | 5〜8 |

## ② 暗唱フレーズ反復（15分）

### 1日の進め方
| 時間 | 内容 |
|------|------|
| 5分 | 新規フレーズ 3〜5本（Ankiから） |
| 5分 | 前日分の復習（声に出す） |
| 5分 | 3日前・7日前の分を復習 |

### 週ごとのターゲット
| 週 | ターゲット | フレーズ数 |
|----|----------|-----------|
| Week 1 | カテゴリー1（相槌）前半 + カテゴリー6（つなぎ）前半 | 〜20本 |
| Week 2 | カテゴリー1 完了 + カテゴリー6 完了 | 35本 |
| Week 3 | カテゴリー2（自己紹介）前半 | 45本 |
| Week 4 | カテゴリー2 完了 + カテゴリー4（依頼）前半 | 65本 |
| Week 5 | カテゴリー3（理由説明）+ カテゴリー4 完了 | 80本 |
| Week 6 | カテゴリー5（感情）完了 | 95本 |
| Week 7〜8 | 全100本の反射出力強化 | 100本 ✅ |

### Ankiカードの作り方
```
表（Front）: 場面の説明（中国語）
             例：「理解了对方说的内容时」

裏（Back）: 日本語フレーズ
             例：「なるほど。」

タグ: week1, cat1_reaction, priority1
```

## ③ 実況独り言練習（15分）

### コンセプト
**今目の前で起きていることを、中国語を経由せず、直接日本語で言葉にする。**
難しい単語は使わなくていい。3語でも4語でも、声に出すことが大事。

### 週ごとの目標
| 週 | 目標 |
|----|------|
| Week 1〜2 | 1分間、詰まってもいいから続ける |
| Week 3〜4 | 2分間、話題を自分で変えながら続ける |
| Week 5〜6 | 3分間、感情・理由をつけて話す |
| Week 7〜8 | 5分間、テーマを決めて自由に話す |

### シーン別スクリプト例

**🌅 朝の準備**
```
今、起きました。
外を見ると、今日は曇っています。
少し眠いですが、シャワーを浴びます。
今日の朝ご飯は〔食べ物〕にしようと思います。
今日は〔予定〕があります。
少し緊張しています。でも、頑張ります。
```

**🚇 通勤・通学**
```
今、電車に乗っています。
〔路線名〕に乗っています。
今は〔駅名〕駅あたりだと思います。
混んでいますが、座れました。
窓の外に〔景色〕が見えます。
今日は〔天気〕です。
あと〔時間〕分くらいで着く予定です。
```

**🍱 昼ご飯**
```
今、昼ご飯を食べています。
今日は〔食べ物〕にしました。
〔味の感想〕です。
少し〔量・値段〕ですが、おいしいです。
ここは〔場所〕の近くにあります。
また来たいと思います。
```

**🌙 一日の振り返り**
```
今日は〔したこと〕をしました。
〔出来事〕があって、〔感想〕でした。
難しかったことは〔こと〕です。
でも、〔よかったこと〕はよかったと思います。
明日は〔予定〕がある予定です。
〔目標〕を頑張りたいと思います。
```

## ④ 発音・アクセント矯正（15分）

### Week別フォーカス
| 週 | フォーカス |
|----|-----------|
| Week 1〜2 | 長音（oo/uu/ee）・拗音（きゃ、しゅ、ちょ等） |
| Week 3〜4 | 促音（きって、ざっし）・鼻音（ほんとう、みんな） |
| Week 5〜6 | アクセント（箸 vs 橋）・イントネーション |
| Week 7〜8 | 自然な話速・音の連結（てにをはの弱化） |

### 毎日の練習セット（5分）

**発音ウォームアップ（2分）**
```

たちつてと / なにぬねの / はひふへほ
まみむめも / やゆよ / らりるれろ / わをん
```
