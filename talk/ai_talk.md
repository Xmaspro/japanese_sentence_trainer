# AI 日语口语练习

目标：每天用 Grok、Claude、Gemini 等 AI 的语音模式进行 30 分钟练习，在真实对话中积累能反复使用的表达。

## 一、每天 30 分钟练习流程

### 1. 热身（5 分钟）

不看稿回答三个简单问题：

- 今日はどんな一日でしたか。
- 今、どんな気分ですか。
- 今日、何を練習したいですか。

启动语：

> 今日は日本語の会話練習に付き合ってください。会話中は、意味が通じない間違いだけ短く直してください。細かい間違いや、もっと自然な言い方は、会話が一段落してからまとめて教えてください。

### 2. 主题对话（15 分钟）

每次只选一个主题。先连续对话，不要一开口就追求完美。

#### 日常话题

1. 自我介绍
2. 今天做了什么
3. 兴趣爱好
4. 最近看过的电影或动漫
5. 在日本的生活：饮食、天气、交通

#### 深入交流

1. 为什么来日本、为什么学日语
2. 未来的梦想和职业规划
3. 日本和中国的文化差异
4. 工作经验和学生时代
5. 压力大时如何放松

#### 求职面试

1. 自己紹介
2. 志望動機
3. 自分の強みと弱み
4. チームで協力した経験
5. 失敗した経験と、そこから学んだこと
6. 5年後、どのようになっていたいか

### 3. 纠错与重说（5 分钟）

让 AI 只挑最值得改的 3 处：

> 今の会話から、特に直したほうがいい表現を3つ選んでください。それぞれについて、①私が言った表現、②自然な表現、③短い理由、④もう一度答えるための質問、の順で教えてください。

听完修改后，不看答案重新回答一次。重点不是记规则，而是把自然表达亲口说出来。

### 4. 素材积累（5 分钟）

让 AI 提取今天可以复用的内容：

> 今日の会話から、今後も使えそうな表現を5つ選んでください。「表現・意味・短い例文」の形でまとめてください。難しすぎる表現は避けて、N3レベルで実際の会話によく使うものを選んでください。

每天只保存 3～5 个表达。第二天热身时，刻意用其中两个造句。

## 二、通用 Prompt

复制后替换主题即可：

```text
あなたは、優しくて話しやすい日本語の会話パートナーです。
私は日本語能力試験N3くらいの学習者です。

今日のテーマ：［ここにテーマを書く］
会話の場面：［日常会話／友達との会話／職場／面接］

次のルールで会話してください。
1. 基本的に日本語だけを使ってください。
2. 一度に一つだけ、答えやすい質問をしてください。
3. 私の答えに短く反応してから、内容を掘り下げてください。
4. 私が言葉に詰まったら、すぐに答えを言わず、簡単なヒントをください。
5. 意味が通じない間違いはその場で短く直してください。
6. 細かい間違いや自然な言い換えは、3～5往復ごとにまとめてください。
7. 教科書的すぎない、自然な「です・ます」調を使ってください。

それでは、簡単な質問から始めてください。
```

### 自我介绍

```text
今日のテーマ：初対面の人に自然に自己紹介する練習
会話の場面：交流会で初めて会った人との会話
```

### 自由聊天

```text
今日のテーマ：最近あったことについての雑談
会話の場面：友達との会話
```

### 面试练习

```text
今日のテーマ：日系企業の面接で志望動機を伝える練習
会話の場面：就職面接

面接官として質問してください。私の回答が終わるまでは途中で直さず、回答後に「内容・日本語・伝え方」の3点からフィードバックしてください。その後、同じ質問にもう一度答えさせてください。
```

### 听不懂时

尽量先用日语请求帮助，不要马上切换中文：

- もう一度、少しゆっくり言ってもらえますか。
- もう少し簡単な言葉で説明してもらえますか。
- 「〇〇」はどういう意味ですか。
- 例えば、どんなことですか。
- 少し考える時間をください。

## 三、每周主题安排

| 星期 | 主题 | 当天重点 |
| --- | --- | --- |
| 周一 | 自我介绍＋周末做了什么 | 流畅地说满 1 分钟 |
| 周二 | 兴趣爱好＋最近看的作品 | 表达理由和感受 |
| 周三 | 学日语的原因＋文化差异 | 举一个具体例子 |
| 周四 | 职业规划＋强项和弱点 | 使用职场表达 |
| 周五 | 模拟面试 | 结论先行，回答有结构 |
| 周六 | 自由聊天 | 提高反应速度 |
| 周日 | 一周复盘 | 重说本周最难的 3 个问题 |

## 四、练习记录模板

```markdown
### YYYY-MM-DD｜今日主题

- 今天能顺利表达的内容：
- 卡住的问题：
- 自然表达：
  - 日语：
    中文：
    我的例句：
- 最重要的一处纠错：
- 明天热身时要复用的两个表达：
```

## 五、练习原则

- 先说完，再纠错；不要让纠错打断表达欲。
- 一次只改 3 个高频问题，避免信息过载。
- 同一个主题隔几天再练一次，用重复换流畅度。
- 不只收藏表达，每个表达都要自己造句并说出口。
- 面试回答录音后再听一遍，重点检查停顿、语速和结论是否清楚。
